# Contributor Covenant Code of Conduct

We are committed to making participation in Repo Triage Kit welcoming and respectful for everyone.

## Our standards

Examples of behavior that contributes to a positive environment include:

- Being considerate, constructive, and respectful of differing viewpoints.
- Giving and accepting feedback with care.
- Focusing criticism on ideas and code rather than people.
- Respecting privacy and never sharing private repository data or credentials.

Unacceptable behavior includes harassment, discrimination, personal attacks, sexualized language or imagery, doxxing, and publishing another person's private information.

## Project maintainers

Project maintainers may remove, edit, or reject contributions that do not follow this Code of Conduct. They may temporarily or permanently exclude contributors for behavior they consider inappropriate, threatening, or harmful.

## Reporting

Report concerns privately to the repository maintainers through GitHub. Do not include credentials, private issue text, or other sensitive repository data in a public report.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
